# 一亩三分地本地工具

每天自动完成一亩三分地的**签到**和**每日答题**，持续攒大米、保持连续签到，你不用动手。全程在你自己的电脑、用你自己的登录完成，不经过任何第三方服务。

支持 **macOS 与 Windows**，都需要 **Chrome + Python 3.12**。账号身份、密码、浏览器会话和数据库只留在本机：密码在 macOS 存进登录钥匙串、在 Windows 用 DPAPI 加密，都不写进仓库。除签到答题外，还能采集 Stripe 面经、离线搜索和导出，也能接入 MCP 客户端。

## 它到底怎么做的（为什么可以放心用）

它不是在服务器上用打码平台替你操作，而是在你本机开一个专用的 Chrome，用你自己的登录会话，按网页正常流程点按钮。下面是每一步的真实机制。

### 签到

打开签到页，选「没心情」，然后提交签到。**它不会替你写任何今日心情或说说，你的主页不会多出一条内容。** 提交后它会去读你的积分流水，确认当天的「签到奖励」大米真的到账，这一步才算成功。

### 每日答题

从网站接口读出当天的题目和所有选项，拿去和一份内置题库逐字比对。题库就是仓库里的 [`answers.json`](outputs/一亩三分地本地工具/answers.json)（194 道题，纯文本问答对，你可以直接打开看，比如「Apollo 11 是哪一年登月的？」→「1969」）。命中就点对应选项、提交，再确认「每日答题」奖励到账。

题库里没有的题，它**不会瞎猜**：直接标记 `answer_needed` 停下，由你补一次正确答案（也可以让 AI 助手查一次再填），答案按选项文字精确匹配，不按 A/B/C 的位置。补过之后这道题就记住了。

### 关于心情 / 日记

签到页可以写「今日心情 / 说说」，发出去会变成你主页上的一条记录（也就是日记）。工具默认选「没心情」，**不替你发布任何内容**，让主页保持干净、也不以你的名义对外说话。

如果你觉得每天一格「没心情」太像机器，可以在 `work/local-toolkit-state/account.json` 里加一行 `"checkin_mood_random": true`（必须是布尔值）显式开启随机心情：签到时按偏日常的分布抽一个心情（前一天的心情有一定概率延续），再从随仓库分发的 `mood-phrases.json` 里该心情的分组抽一句中性短句填进「说说」，最近 30 天用过的句子不重复。**开启后每天会以你的名义在主页发布一句话**，这是你的选择，工具不会替你决定；没写这一行时行为与以前完全一致。奖励核验不变。

### 判定成功的标准

它不把「点到了按钮」或「命令退出码 0」当成功。**只有查到当天、你账号名下、正数的大米奖励流水，签到和答题两项才报 `complete`。** 网站改版、网络或人机验证出问题时如实报失败，不谎报成功。所有运行结果都存在本机，可离线复查。

## 最快用法：交给 AI 助手

把仓库交给一个能在本机执行命令的 AI 编程助手（Claude Code、Codex 等），说“装好并配置每天自动签到答题”。它会完成克隆、建环境、装依赖、跑检查、部署每日计划。你只需提供论坛用户名和 uid，并在它弹出的安全输入框里输一次密码——密码进系统钥匙串 / DPAPI，不进仓库、不进对话。之后每天自动运行。

想自己动手，按[完整教程](outputs/一亩三分地本地工具/README.md)来，结果一样。

## 几点须知

- 每位使用者配置自己的论坛账号，不会继承别人的登录、资料或每日计划；克隆本身不会创建计划，也不会执行任何网站操作。
- 读取内容以当前账号的权限为准。帖子详情或站内搜索返回结果，不等于已存进资料库。
- 已有实测不构成永久通过 Cloudflare 的保证；网站或验证变化可能导致某天失败，程序会如实记录。
- 发帖、回复、收藏、点赞等互动命令默认只预览，带 `--submit` 才真正写站点，提交后都会回读核对；顶/踩、评分这类不可撤销或要花大米的操作，工具不做。
